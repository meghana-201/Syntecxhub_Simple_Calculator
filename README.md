# Simple Calculator

## Project Description

A simple command-line calculator developed using Python as part of my Syntecxhub Python Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid input handling
- Repeated calculations
- Clear option
- Exit option

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Open `calculator.py`.
3. Run the program.
4. Select an option from the calculator menu.
